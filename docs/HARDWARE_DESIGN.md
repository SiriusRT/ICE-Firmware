# ICEBOX 智能冰柜主控板硬件设计参考手册 v2.0

> 对应固件：`ICE-Firmware`（协议 v1.2，`docs/BLE_PROTOCOL.md`）
> 主控：**ESP32-WROOM-32-N4**（双核 Xtensa LX6 @240MHz，520KB SRAM，4MB Flash）
> 本版架构变更：**移除物理旋钮与 OLED**；TEC 采用 **24V/3A** 功率级；输入 PD3.0 20V。

## 1. 系统总览与供电架构

```
                    USB-C PD 65W (20V) ──► [输入保护/防反接] ──► VBUS_SYS (5~20V)
                    12V DC 电源输入(点烟器) ──┘

         ┌────────────────────────────────────────────────────────────────┐
         │ 逻辑域：Buck 宽压 5~24V→3.3V (0.3A)  →  ESP32/INA226/CH340K    │
         │ 功率域：Boost 20V→24V (3A+)  →  24V 母线  →  TEC 功率级(24V/3A) │
         │          Buck 24V→12V (1A)    →  12V 母线  →  4针风扇           │
         └────────────────────────────────────────────────────────────────┘
         烧录自举：PC 插入时 VBUS≈5V → 宽压 Buck 输出 3.3V 点亮 ESP32 即可下载；
                   此时 Boost/Buck(12V) 无输出（烧录期不制冷/不转扇，符合预期）

ESP32-WROOM-32-N4
 ├─ UART0 ←→ CH340K ←→ Type-C D+/D-（电脑烧写固件 + 日志）
 ├─ BLE（板载天线，注意净空区）  ←→ 微信小程序
 ├─ WiFi（预留）                 ←→ 后续远程控制
 ├─ LEDC PWM → TEC 功率级（24V，15kHz）
 ├─ LEDC PWM → 风扇 PWM 脚（25kHz，经 3.3V→5V 接口）   ← TACH 测速反馈
 ├─ OneWire ← DS18B20（柜内/冷侧/热侧）
 ├─ ADC     ← NTC（主控板温，可选）
 ├─ I2C     ← INA226 + PD Sink(CH224K，可选 I2C)
 └─ 软关机锁存（GPIO13）；预留 GPIO32/33/34（原旋钮）
```

**电源树（v2.0）**

| 级 | 输入 | 输出 | 器件（参考） | 说明 |
|---|---|---|---|---|
| 输入保护 | USB-C VBUS / DC Jack | VBUS_SYS | TVS(SMBJ30A) + PTC(5A) + 防反接(P-MOS/肖特基) | 反接/浪涌，耐压 ≥40V |
| PD Sink | USB-C CC1/CC2 | 20V/65W 请求 | CH224K | 协商 20V@3.25A |
| 逻辑 Buck | VBUS_SYS 5~24V | 3.3V@0.3A | MP2315 / TPS62125 / SY8303 | **宽压**：PC 5V 烧录自举 + PD 20V 均可用 |
| 功率 Boost | 20V | 24V@3.5A | 升压（同步整流，如 XL6019/MT3608 级别需扩流或专用 24V/3A） | 供 TEC 24V 母线；持续 2.5A(60W) |
| 风扇 Buck | 24V | 12V@1A | MP1584 / SY8120 | 供 4 针风扇 12V |
| TEC 驱动 | 24V | 24V PWM | 低侧 N-MOS + 续流 | 见 §3.3 |
| 风扇开关 | 12V | 12V 通断 | 低侧 N-MOS | 见 §3.4 |

> **注意**：PD3.0 PDO 最高 20V，24V 必须由 Boost 升压获得。TEC 额定 **24V/3A（约 72W）**，持续按 60W（≈2.5A）运行 → 占空比上限约 83%，且瞬时电流必须 ≤ Imax（见 §3.3）。

## 2. 电气接口定义

### 2.1 Type-C 供电+数据接口（J1）

单口承担「PD 取电（20V/65W）+ USB2.0 数据（烧录/日志）」。选用 **16Pin Type-C 母座**（免 USB3.0 超高速脚），卧贴引脚细、不便手焊时改用「Type-C 转 2.54 排针模块」或面板式母座+延长线（见 §3.9）。

| Pin | 网络 | 去向 | 说明 |
|---|---|---|---|
| A1/B1,A12/B12 | GND | 电源地 | 与功率地单点汇合 |
| A4/A9,B4/B9 | VBUS | 输入保护 → VBUS_SYS | 5~20V，PTC(5A)+TVS(SMBJ30A) |
| A5,B5 | CC1/CC2 | → CH224K | PD 协商，勿直下 5.1k |
| A6/A7,B6/B7 | D+/D- | → ESD → CH340K | USB2.0 数据 |
| A8/B8 | SBU | 悬空 | 不用 |
| SHELL | 屏蔽 | 1MΩ//0.1µF → GND | ESD |

### 2.2 4针风扇接口（J2，12V）

| Pin | 网络 | 说明 |
|---|---|---|
| 1 | GND | 地 |
| 2 | +12V | 12V 母线恒供（24→12 Buck） |
| 3 | TACH | 开漏，板上拉 10k→3.3V，接 GPIO27（PCNT） |
| 4 | PWM | 25kHz，**3.3V PWM → 5V 开漏接口** 后接入（见 §3.4） |

### 2.3 TEC 输出（J3，24V）

| Pin | 网络 | 说明 |
|---|---|---|
| 1 | 24V 母线（经低侧 MOS 斩波后） | TEC+ |
| 2 | 24V 母线源 | 见 §3.3 |
| 3 | GND | 功率地（采样单点接地） |

### 2.4 温度传感器

| 接口 | 信号 | 引脚 | 说明 |
|---|---|---|---|
| OneWire | DQ | GPIO4 | 4.7kΩ→3.3V；DS18B20 三路：柜内(防水)、冷侧、热侧（可加第二路柜内） |
| 板载 NTC(可选) | NTC | GPIO36 | 10k NTC + 10k 上拉 + 100nF |

DS18B20 接线顺序与固件索引一致：`0=柜内、1=(可空/柜内2)、2=冷侧、3=热侧`。缺失路固件自动判无效（`INT16_MIN`）不误报。

### 2.5 I2C（共享）

| 信号 | 引脚 | 器件 | 地址 |
|---|---|---|---|
| SDA/SCL | GPIO21/22 | INA226、CH224K(可选) | 0x40 / 0x75 |

上拉 4.7k→3.3V。（OLED 已移除。）

### 2.6 预留 GPIO（原旋钮）

| GPIO | 用途 | 备注 |
|---|---|---|

| 33 | 预留 | 原 EC11-B |
| 34 | 预留(仅输入) | 原旋钮按键，可作拨码/唤醒 |

## 3. 外围功能电路

### 3.1 PD Sink（CH224K）

同 v1.0 方案：CC1/CC2 → CH224K 请求 20V@3.25A（CFG 电阻固定或 I2C 0x75）；CC 勿并 5.1k；VBUS ≥35V 储能电容。

### 3.2 电源树实现要点

- **逻辑 3.3V 宽压 Buck**：5~24V 输入。PC(5V) 与 PD(20V) 都可用；PD 协商 5V→20V 跳变时保持输出。
- **20V→24V Boost**：TEC 持续 2.5A（60W），Boost 需按 **≥3A/24V（~75W 峰值）** 设计并留裕量；输出 24V 母线加 **大电解 + 陶瓷** 支撑 PWM 斩波瞬态；建议同步整流型升压提升效率。输入侧注意 20V PTC 载流。
- **24V→12V Buck**：风扇 12V（≤1A），从 24V 取电。
- 3.3V 加 LC 滤波（ESP32 射频敏感）。

### 3.3 TEC 24V 功率驱动（核心）

- **拓扑**：低侧 N-MOS 斩波，15kHz；续流 **Schottky** 跨 TEC；24V 母线大电容。
- **选型约束（重要）**：TEC 额定 24V/**3A（Imax）**。
  - 持续 60W → 占空比上限 ≈ 60/(24×3) ≈ **83%**；
  - 开通瞬时电流 = 24V/R，须保证 **≤ Imax**，避免超过 TEC 额定；
  - 栅极：3.3V 逻辑电平 N-MOS（低侧，Vgs=3.3V 时 Rdson 达标），大栅荷加栅驱；
  - 固件侧 `PELTIER_FULL_POWER_W` 应按 **24V 母线 + 该 TEC 的 R** 换算占空比-功率，供电识别 clamp（协议 v1.2）据此限幅。
- **保护**：INA226 实时监测母线电压/电流/功率；过流/过功率→降载或停机（报警码 5）。

### 3.4 风扇接口电路（4针）

- **电源**：12V 恒供；经一只低侧 N-MOS 做**电源总闸**（通断/过热联动，非调速）。
- **调速**：走风扇 **PWM 脚**（4 号，25kHz）。**PWM 接口（回答 3.3V 是否可直驱）**：
  - 直连 3.3V PWM 对多数 4 针风扇可用（阈值通常 ~2.5V），但 ATX 规范要求 5V 开漏驱动，个别风扇全速档不满；
  - **推荐**：`ESP32(26) ── 74AHCT1G125(5V供电) 或 2N7002 开漏 ── 5V 上拉 ── 风扇 PWM脚`，保证满速档正确；
  - 串 10Ω 防振铃。
- **测速**：TACH 开漏 → 10k 上拉 3.3V → GPIO27（2 脉冲/转）。闭环调速与堵转报警（报警码 6）依赖它。

### 3.5 电气量监测（INA226）

同前：5mΩ Kelvin 采样输入母线，I2C 0x40；量程按 TEC 峰值电流留裕（5A）。为供电识别（PD/QC/12V）与过流/过功率提供数据。

### 3.6 温度采集

DS18B20×3（柜内防水 / 冷侧 / 热侧 TO-92），单总线 4.7k；顺序与固件一致。NTC 板温（GPIO36）可选。

### 3.7 LED 状态指示（可选，替代 OLED）

- 1× 运行/连接指示（GPIO 自由选，如 32）
- 1× 报警指示（如 33）
- 或 LED 并入现有 GPIO；固件 `LED` 任务按需。

### 3.8 USB-UART 下载桥（CH340K）

同 v1.1 方案 A 说明：CH340K VCC=3.3V；RTS#/DTR# 经 2×NPN/2N7002 反相接 GPIO0/EN 自动下载；**RTS#/DTR# 引出情况以 CH340K 数据手册为准**，若无则改手动 BOOT/EN。烧录自举靠 §3.2 宽压 3.3V。

### 3.9 Type-C 焊接友好替代（J1）

- 卧贴 16P 引脚细；手焊建议用 **Type-C 转 2.54 排针模块**或**面板母座 + 延长线**接到主板端子（主板只留大间距焊盘），量产再考虑 16P 混装（4 插件脚 + SMD 信号脚）。

### 3.10 保护与 EMC

- 输入 TVS(SMBJ30A)+PTC(5A)+防反接。
- 24V Boost + PWM 斩波：母线大电容、续流、栅极串阻抑制振铃；功率走线加宽。
- INA226 Kelvin 采样；地单点。
- ESP32 天线净空；金属结构远离 ≥10mm。

## 4. 设计检查清单

- [ ] CC → CH224K 请求 20V@65W（非 5.1k 直下）
- [ ] 逻辑 3.3V 用宽压 Buck（5~24V），PC 5V 可烧录自举
- [ ] Boost 20V→24V 载流 ≥3A（TEC 2.5A 持续 / 3A 峰值），24V 母线大电容
- [ ] 24V→12V Buck 供风扇
- [ ] TEC 驱动：低侧 N-MOS + 续流；占空比 ≤~83%（60W/24V/3A）；瞬时 ≤Imax
- [ ] 风扇：12V 恒供 + PWM 脚调速（3.3V→5V 开漏接口）+ TACH 测速保留
- [ ] INA226 保留（供电识别 + 过流/过功率）
- [ ] DS18B20（柜内/冷/热）单总线 4.7k，顺序与固件一致
- [ ] CH340K VCC=3.3V，RTS#/DTR#（以数据手册核对）自动下载
- [ ] 无旋钮/OLED：确认固件裁剪 encoder/display；预留 GPIO 32/33/34
- [ ] 引脚避开启动脚（0/2/5/12/15）
