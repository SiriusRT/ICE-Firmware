# ICEBOX 智能冰柜主控板硬件设计参考手册 v1.0

> 对应固件：`ICE-Firmware`（协议 v1.1，`docs/BLE_PROTOCOL.md`）
> 主控：**ESP32-WROOM-32-N4**（双核 Xtensa LX6 @240MHz，520KB SRAM，4MB Flash）
> 系统：半导体制冷片（Peltier）60W + 电脑 CPU 散热器风扇（4针）的小型冰柜主控板。

---

## 1. 系统总览与供电架构

> **Type-C 接口方案（定稿 = 方案 A）**：单个 USB-C 口同时承担 **PD 取电（CC 协商）+ USB2.0 数据（烧录/日志，D+/D-）**。
> QC / 融合快充（走 D+/D-）**不在此口支持**——D+/D- 已被 USB 数据占用，二者物理互斥。QC/12V 请走独立 DC 输入。

```
                    USB-C PD 65W (20V) ──┐
                    12V DC 电源输入(点烟器) ├─→ [输入保护/防反接] ─→ VBUS_SYS (5~20V)
                                          │                            │
         ┌────────────────────────────────┴───────────────────────────┴──────────────┐
         │  逻辑域：Buck L 宽压 5~24V→5V(0.5A) ─→ LDO 5V→3.3V ─→ ESP32/OLED/传感器      │
         │  功率域：Buck P 20V→12V(6A) ──────────────────→ 12V 母线(制冷片+风扇)        │
         └───────────────────────────────────────────────────────────────────────────┘
         烧录自举：PC 插入时 VBUS≈5V → Buck L 仍输出 5V → 3.3V 点亮 ESP32 即可烧录；
                   此时 Buck P 无输出（12V 功率轨断电，烧录期不制冷，符合预期）

ESP32-WROOM-32-N4
 ├─ UART0 ←→ CH340C ←→ Type-C D+/D-（电脑烧写固件 + 日志）
 ├─ BLE（板载天线，注意净空区）  ←→ 微信小程序
 ├─ WiFi（预留）                 ←→ 后续远程控制
 ├─ LEDC PWM → Peltier 功率级（15kHz）
 ├─ LEDC PWM → 4针风扇 PWM（25kHz）   ← TACH 测速反馈
 ├─ OneWire ← DS18B20×4（柜内×2/冷侧/热侧）
 ├─ ADC     ← NTC（主控板温）
 ├─ I2C     ← INA226（电压/电流/功率） + OLED + PD Sink(CH224K)
 ├─ 旋钮 EC11（A/B/按键）
 └─ 软关机锁存（GPIO13）
```

**电源树（方案 A 定稿）**

| 级 | 输入 | 输出 | 器件（参考） | 说明 |
|---|---|---|---|---|
| 输入保护 | USB-C VBUS / DC Jack | VBUS_SYS | TVS(SMBJ30A) + PTC(3A) + 防反接(P-MOS/肖特基) | 反接/浪涌保护，耐压 ≥40V |
| PD Sink | USB-C CC1/CC2 | 20V/65W 请求 | CH224K | 协商 20V@3.25A（详见 §3.1） |
| **Buck L（逻辑，新增）** | VBUS_SYS 5~24V | 5V@0.5A | MP1584 / SY8303 / TPS62125 | **宽压输入**：PC 烧录 5V 与 PD 20V 均可用，保证烧录自举 |
| LDO 5→3.3 | 5V | 3.3V | AMS1117-3.3 / ME6211 | ESP32 及逻辑电源，3.3V 加 LC 滤波 |
| Buck P（功率） | VBUS_SYS 20V | 12V@6A | SY8368A / MP2315 | 12V 母线（Peltier+风扇），输入≥14V 才工作 |
| 制冷驱动 | 12V | 12V PWM | N-MOS 功率级 | 见 §3.3 |

> 相比早期「20V→12V→5V→3.3V」链式拓扑，方案 A 把**逻辑 5V 改为宽压直取 VBUS_SYS**，是为「电脑 5V 烧录」特意做出的改动：烧录时 Buck P 关闭，但 Buck L 仍能把 5V 变成 5V→3.3V 点亮主控。若 PC 侧需要同时跑制冷（一般不需要），可忽略。

## 2. 电气接口定义

### 2.1 Type-C 供电+数据接口（J1，方案 A）

**用途**：单口承担「PD 取电（最高 20V/65W）供电」+「USB2.0 数据（固件烧录/串口日志）」。

| Pin | 网络 | 去向 | 说明 |
|---|---|---|---|
| A1/B1, A12/B12 | GND | 电源地 | 与功率地单点汇合 |
| A4/A9, B4/B9 | VBUS | → 输入保护 → VBUS_SYS | 5~20V，PTC 3A + TVS SMBJ30A |
| A5, B5 | CC1/CC2 | → CH224K 的 CC1/CC2 | **PD 协商专用**，勿直接下拉 5.1k |
| A6/A7, B6/B7 | D+/D- | → ESD(USBLC6-2) → CH340C | **USB2.0 数据**（不接 QC 检测） |
| A8/B8 | SBU1/2 | 悬空（或接 100k 下拉） | 本设计不用 |
| 外壳 | SHELL | → GND（经 1MΩ + 0.1µF RC） | 避免 ESD 直接打地 |

**信号级连接图**

```
                     ┌────────────┐                    ┌──────────────┐
 VBUS ───────────────┤ 输入保护    ├──► VBUS_SYS ──► Buck L → 5V → 3.3V 逻辑
                     │(TVS/PTC/防反)│        │
                     └────────────┘        └──► Buck P → 12V（Peltier/风扇）
 USB-C J1
  ├─ CC1 ──► CH224K.CC1                  CH224K (PD Sink, 请求 20V@3.25A/65W)
  ├─ CC2 ──► CH224K.CC2                   ├─ CC1/CC2 ← USB-C
  ├─ D+ ───► ESD ──► CH340C.DP          ├─ VBUS 出（与输入 VBUS 同点）
  ├─ D- ───► ESD ──► CH340C.DM          └─ CFG1/CFG2：电阻固定 20V，或 SDA/SCL(I2C,0x75) 动态
  └─ VBUS/GND ──► 电源树
 CH340C → TXD/RXD ↔ ESP32 UART0(RX0/TX0)，RTS#/DTR# → 自动下载电路（见 §3.8）
```

**设计要点**
- CC 必须经 CH224K 处理才能协商高电压；5V-only 场合（插电脑）CH224K 请求被拒 → VBUS 保持 5V → Buck L 兜底点亮 ESP32 完成烧录。
- D+/D- 与 PD 协商互不干扰：PD 充电器的 D+/D- 悬空/短路，CH340C 无主机不枚举，不影响取电；只有接电脑时 CH340C 才作为 COM 口出现。
- 由于 D+/D- 被数据占用，**本口不兼容 QC/融合快充**（其握手依赖 D+/D-）。QC/12V 由独立 DC 输入承担（见 §1）。
- 防 ESD：D+/D- 加 USBLC6-2；CC 加 ESD（可用同芯片的 CC 通道或 5kΩ 串阻）。
- VBUS 输入端储能电容 ≥35V 耐压（PD 20V 时），建议 100µF 电解 + 22µF 陶瓷。
- 外壳 SHELL 用 1MΩ//0.1µF RC 接地，抑制 ESD 与回流。

### 2.2 4针电脑风扇接口（J2，兼容 ATX 规范）

| Pin | 网络 | 说明 |
|---|---|---|
| 1 | GND | 地 |
| 2 | +12V | 12V 母线供电（风扇 ≤ 1.5A） |
| 3 | TACH | 开漏转速输出，**2 脉冲/转**，板上拉 10kΩ→3.3V，接 GPIO27（PCNT 输入） |
| 4 | PWM | 25kHz 控制信号，经电平转换 → 5V 逻辑，接 GPIO26 |

**设计要点**
- TACH 为开漏，上拉到 **3.3V** 即可被 ESP32 直接读取（GPIO27 非 5V 耐受）。
- PWM 建议 **开漏/三态 + 5V 上拉**（如 74AHCT1G125 缓冲，或 NPN 反相驱动），保证风扇满速档位正确；直接用 3.3V 驱动大多数 4 针风扇亦可，但个别风扇需 5V 才能全速。
- 建议加 10Ω 串联电阻抑制振铃。
- 选型：12V 4针 PWM 风扇，沿用 CPU 散热器自带风扇即可；推荐 92/120mm，转速范围 600~4200RPM（与固件默认折线匹配）。

### 2.3 半导体制冷片输出（J3）

| Pin | 网络 | 说明 |
|---|---|---|
| 1 | +12V（经功率级） | Peltier 电源输入，PWM 斩波 |
| 2 | 12V 母线（源） | 直连或经 MOS 后 |
| 3 | GND | 地（采样地注意单点接地） |

**设计要点**
- 60W 半导体制冷片在 12V 下约 5A，需 **≥5A** 的功率级与走线。
- 详见 §3.3。

### 2.4 温度传感器接口

| 接口 | 信号 | 引脚 | 说明 |
|---|---|---|---|
| OneWire 总线（J4 共 4 路） | DQ | GPIO4 | 4.7kΩ 上拉→3.3V；DS18B20×4 按 ROM 区分 |
| 板载 NTC | NTC | GPIO36 (ADC1_CH0) | 10kΩ NTC + 10kΩ 上拉 + 100nF 滤波 |

DS18B20 布线顺序（固件索引固定）：0=柜内1（防水探头）、1=柜内2（防水探头）、2=冷侧（TO-92 贴制冷片冷面）、3=热侧（TO-92 贴 CPU 散热器底座）。

### 2.5 I2C 总线（共享）

| 信号 | 引脚 | 器件 | 地址 |
|---|---|---|---|
| SDA | GPIO21 | INA226 / OLED / CH224K(可选) | 0x40 / 0x3C / 0x75 |
| SCL | GPIO22 | 同上 | — |

上拉 4.7kΩ→3.3V。

### 2.6 旋钮（EC11）接口

| 信号 | 引脚 | 说明 |
|---|---|---|
| A 相 | GPIO32 | 上拉 + 可选 10nF 滤波 |
| B 相 | GPIO33 | 上拉 + 可选 10nF 滤波 |
| 按键 | GPIO34 | 上拉，接 GND（低有效） |

### 2.7 电源开关与软关机

| 信号 | 引脚 | 说明 |
|---|---|---|
| 机械开关 | 主回路 | 物理通断（可选） |
| 软锁存 | GPIO13 | P-MOS 锁存电路，长按旋钮可软关机（固件预留） |

| GPIO | 功能 | 用途 | 备注 |
|---|---|---|---|
| 4 | OneWire | DS18B20×4 | 上拉 4.7k |
| 13 | GPIO | 软关机锁存 | 预留 |

## 3. 外围功能电路模块（功能 + 推荐选型）

### 3.1 PD Sink（Type-C 取电）

- **功能**：通过 USB-C CC 通道向电源适配器协商 **20V/3.25A（65W）**；本设计只取电、不做 USB host/device 枚举。
- **推荐选型（定稿 = CH224K）**
  - **CH224K（WCH）**：低成本（~¥1-2）、支持 5/9/12/15/20V、最高 100W，供电能力档通过 CFG 引脚或 I2C 配置。
    - **硬件固定 20V**：按 CH224K 数据手册的 CFG1/CFG2 组合接上/下拉电阻，锁定 20V/3.25A 档（量产简单可靠，推荐）。
    - **I2C 动态**：SDA/SCL → ESP32 共享 I2C 总线（地址 0x75），固件可在 PD 与低档间动态切换（当前协议固件不切档，默认 20V）。
  - **STUSB4500（ST）**：I2C 全可编程 + OTP，成本略高，适合量产替代。
- **原理图连接**
  ```
  J1.CC1/CC2 ──(ESD)──► CH224K.CC1 / CC2
  VBUS_SYS(输入) ──────── CH224K 自身供电（内部 LDO），VBUS 端 ≥35V 储能电容
  CH224K 的功率输出与 VBUS_SYS 同点（经 PTC/TVS 后），PD 协商成功后 VBUS 升到 20V
  CFG1/CFG2：电阻固定 20V 档；或 SDA/SCL 接 ESP32 I2C(0x75)
  ```
- **设计要点**
  - CC 只接 CH224K，**不要**在 CC 上并 5.1k 下拉（会抢占 sink 角色）。
  - CC 走线加 ESD 保护；VBUS 端 ≥35V 耐压电容（100µF 电解 + 22µF 陶瓷）。
  - 若只用 PD 供电而不需本口数据，可将 D+/D- 留空；但方案 A 需保留（烧录用）。
  - 供电信息（PD/QC/电压档）由固件经 FFB5 `supply_protocol/max_power` 上报并限功率（协议 v1.2）。

### 3.2 DC-DC 电源树

- **Buck 20V→12V（6A）**：SY8368A、MP2315、TPS54560。
  - 输出 12V 母线同时供风扇（≤1.5A）与 Peltier 功率级（≤5A），峰值考虑 **≥6A** 裕量；加 470µF 电解 + 22µF 陶瓷。
- **Buck/LDO 12V→5V**：MP1584 / SY8120（100mA 即可，供 UART 桥等）。
- **LDO 5V→3.3V**：AMS1117-3.3 或 ME6211（低噪声），ESP32 射频对 3.3V 纹波敏感，建议 LC 滤波。

### 3.3 Peltier 功率驱动（核心模块）

- **功能**：LEDC PWM（15kHz）斩波驱动 Peltier，功率 60W、电流约 5A@12V。
- **推荐电路**：低侧 N-MOS 开关 + 续流二极管
  - 逻辑电平 N-MOS：**AOD4184A**（40V/50A, Rdson≈4.5mΩ@4.5V）或 **CSD19532KCS**。
  - 栅极驱动：3.3V GPIO 直驱对大电流 MOS 略勉强，建议加 **TC4427** 或 **UCC27511** 栅驱；简单方案用 2×BSS138 推挽升压。
  - 续流：**SS54 肖特基** 或更低压降的 Schottky，并 **100µF 电解** 吸收母线纹波。
  - 栅极串 22Ω，PWM 15kHz，占空比 0~100%。
- **过流保护**：INA226（5mΩ 分流电阻，见 §3.5）实时监测；固件侧功率上限 70W 触发报警码 5。

### 3.4 风扇接口电路

- 见 §2.2。TACH 开漏上拉到 3.3V；PWM 经 74AHCT1G125 缓冲到 5V；串 10Ω。

### 3.5 电气量监测（INA226）

- **功能**：监测输入电压/电流/功率，满足协议 0.01V/0.01A/0.1W 精度。
- **选型**：TI **INA226**（I2C，16 位，地址 0x40）。
- **采样电阻**：5mΩ/2W（如 5W 大封装保证温漂），串在输入母线上；量程 0~16.38A。
- **配置**：寄存器 0x4127（连续测量 16 次平均），Calibration 按 5mΩ/5A 计算（固件内置）。
- **设计要点**：分流电阻采样走 **Kelvin 四线** 引到 INA226 的 IN+/IN-；功率 = 母线电压 × 电流，供固件 60W 功率计算与过功率保护。

### 3.6 温度采集

- **DS18B20×4**（OneWire 总线，GPIO4）
  - 柜内×2：**防水探头 DS18B20-WP**（不锈钢封装）。
  - 冷侧/热侧：**TO-92 封装 DS18B20**，热侧贴 CPU 散热器底座（耐温到 125℃，留导热硅脂）。
  - 总线 4.7kΩ 上拉→3.3V；走线 ≤1m，建议双绞/屏蔽。
- **板载 NTC（主控板温）**：10kΩ NTC（B=3950）+ 10kΩ 上拉 + 100nF 滤波 → GPIO36。放置于功率级/12V Buck 附近，监测板温。

### 3.7 OLED 显示

- **选型**：0.96" 128×64 **SSD1306**（I2C，0x3C）或 1.3" **SSD1315**。3.3V 供电。
- 与 INA226 共用 I2C 总线（地址不冲突）。

### 3.8 USB-UART 下载桥

- **选型（定稿 = CH340C，降成本）**：**CH340C**（内置 12MHz 晶振、无需外接晶体、USB2.0 全速、单芯片最省料）比 CP2102N 便宜约一半；量产友好。
- **原理图连接**
  ```
  J1.D+/D- ──► ESD(USBLC6-2) ──► CH340C.DP / CH340C.DM
  CH340C.VCC ◄── 3.3V（关键：VCC=3.3V，UART 高电平即 3.3V，ESP32 引脚非 5V 耐受）
  CH340C.RXD ◄── ESP32.TX0    （交叉连接）
  CH340C.TXD ──► ESP32.RX0
  CH340C.RTS#──► [反相] ──► ESP32.EN(GPIO 复位脚)
  CH340C.DTR#──► [反相] ──► ESP32.GPIO0（下载模式选择）
  ```
- **自动下载（一键烧录）电路**：与官方 ESP32 DevKit 一致，用 **2× NPN/2N7002 反相级**把 CH340C 的 RTS#/DTR#（RS-232 低有效）组合转成 EN 与 GPIO0 时序：
  - GPIO0 与 EN 各上拉 **10kΩ→3.3V**，EN 对地 **1µF**；
  - RTS#/DTR# 各经 **1kΩ** 进三极管基极，集电极分别拉 GPIO0 与 EN；
  - esptool 烧录时序自动控制（该电路与 CP2102/CH340 兼容，Clone 版 DevKit 大量采用）。
- **设计要点**
  - **VCC 用 3.3V**：CH340C 支持 3.3~5V 供电；若用 5V，其 TXD 高电平≈5V，会灌入 ESP32 非耐受引脚，必须加电平转换或分压。建议直接 3.3V。
  - 每个供电脚就近 0.1µF；USB DP/DM 差分走线 ≤15mm、等长。
  - **烧录自举（关键）**：电脑只提供 **5V**（PD 协商不成立），此时 Buck P（20→12V）无输出属正常；逻辑 5V 由 **Buck L 宽压（5~24V→5V）** 从 VBUS_SYS 直接得到 → 3.3V 点亮 ESP32 → 即可枚举下载。烧录期间制冷片不工作。
  - 接 PD 充电器时 CH340C 不枚举（无主机），不影响取电。

### 3.9 旋钮（EC11）

- EC11 带按键，A/B/按键 上拉 10k，接 GPIO32/33/34；可选 10nF 滤波。固件 ISR 正交解码，加速调速（见固件 `task_encoder`）。

### 3.10 电源开关 / 软关机锁存

- 方案 A（简单）：**滑动/翘板开关**串主回路。
- 方案 B（推荐）：**按键 + P-MOS 自锁电路**，GPIO13 拉高维持供电，固件长按旋钮软关机拉低 GPIO13 断电；同时主电源开关做物理总断。

### 3.11 保护与 EMC

- 输入：TVS（SMBJ30A）+ PTC 3A + 防反接肖特基/PMOS。
- Type-C：D+/D- ESD（USBLC6-2）。
- 电源：每个 IC 就近 0.1µF；12V 母线大电解；3.3V LC 滤波。
- Peltier 负载为感性+PWM，注意栅极振铃与续流；走线加宽载流，采样用 Kelvin。
- ESP32 板载 PCB 天线区域**净空**，天线下方禁铺地/走线；金属结构件远离天线 ≥10mm（影响 BLE/WiFi 距离）。

## 4. 设计检查清单

- [ ] USB-C CC 接 CH224K（非直接 5.1k），请求 20V@65W

- [ ] 12V 母线载流 ≥6A，Peltier 支路 ≥5A

- [ ] 风扇：TACH 上拉 3.3V、PWM 25kHz 电平转换、串阻防振铃
