# ICEBOX 智能冰柜主控板硬件设计参考手册 v2.1

> 对应固件：`ICE-Firmware`（协议 v1.2，`docs/BLE_PROTOCOL.md`）
> 主控：**ESP32-WROOM-32-N4**（双核 Xtensa LX6 @240MHz，520KB SRAM，4MB Flash）
> 本版架构变更：**移除物理旋钮与 OLED**；TEC 采用 **24V/3A** 功率级；输入 PD3.0 20V；PD 取电 **CH224A**；**24V→5V** 供栅极驱动与风扇 PWM 接口；CH340K **独立供电 + 防灌设计**。

## MCU 信号命名（Net 命名总表）

**命名规则**：全大写，格式 `被控对象_信号类型缩写`。

| 信号类型缩写 | 含义 | 示例 |
|---|---|---|
| CTRL | 控制信号（PWM 调速/调功） | 控制风扇转速 = `FAN_CTRL` |
| SPD | 转速反馈 | 风扇转速反馈 = `FAN_SPD` |
| TMP | 温度信号（测温对象） | `CABINET_TMP` |
| PWR | 电源通断/锁存 | `FAN_PWR`、`PWR_HOLD` |

**接入 MCU 的信号总表**（方向以 MCU 视角，`I/O`=双向）

| 网络名 | 对象 | 信号说明 | 方向 | MCU 引脚 | 电平/说明 |
|---|---|---|---|---|---|
| `TEC_CTRL` | TEC | 制冷 PWM 功控（0–100%） | 出 | GPIO25 | 3.3V，15kHz → 低侧 MOS 栅极 |
| `FAN_CTRL` | 风扇 | 风扇 PWM 转速控制 | 出 | GPIO26 | 3.3V → 74AHCT1G125 缓冲 → 5V PWM |
| `FAN_SPD` | 风扇 | TACH 转速反馈（2 脉冲/转） | 入 | GPIO27 | 开漏，10k 上拉 3.3V |
| `FAN_PWR` | 风扇 | 12V 电源闸 MOS 栅极（可选） | 出 | （未分配） | 仅作通断，非调速 |
| `TEMP_DQ` | 温度 | OneWire 总线（DS18B20 共享） | I/O | GPIO4 | 4.7k 上拉 3.3V；逻辑端点：`CABINET_TMP`/`COLD_TMP`/`HOT_TMP` |
| `BOARD_TMP` | 主控板 | 板温 NTC（可选） | 入 | GPIO36 | ADC1_CH0，10k 上拉 |
| `I2C_SDA` | 总线 | INA226(供电监测) | I/O | GPIO21 | 4.7k 上拉 3.3V |
| `I2C_SCL` | 总线 | 同上 | I/O | GPIO22 | 4.7k 上拉 3.3V |
| `UART0_TXD` | 下载桥 | ESP32 TX0 → CH340K.RXD | 出 | TX0 | 3.3V |
| `UART0_RXD` | 下载桥 | CH340K.TXD → ESP32 RX0 | 入 | RX0 | 3.3V |

## 1. 系统总览与供电架构

```
                    USB-C PD 65W (20V) ──► [输入保护/防反接] ──► VBUS_SYS (5~20V)
                    12V DC 电源输入(点烟器) ──┘

         ┌────────────────────────────────────────────────────────────────┐
         │ 逻辑域：Buck 宽压 5~24V→3.3V (0.3A)  →  ESP32/INA226/传感器        │
         │ 功率域：Boost 20V→24V (3A+)  →  24V 母线  →  TEC 功率级(24V/3A)     │
         │          Buck 24V→5V (1A)     →  5V 母线  →  栅极驱动(U9) + 风扇PWM  │
         │                                     接口(AHCT125 VCC/5V 上拉)         │
         └────────────────────────────────────────────────────────────────┘
         烧录自举：PC 插入时 VBUS≈5V → 宽压 Buck 输出 3.3V 点亮 ESP32 即可下载；
                   此时 Boost/Buck(5V) 无输出（烧录期不制冷/不转扇，符合预期）

ESP32-WROOM-32-N4
 ├─ UART0 ←→ CH340K（独立供电+防灌） ←→ Type-C D+/D-（电脑烧写固件 + 日志）
 ├─ BLE（板载天线，注意净空区）  ←→ 微信小程序
 ├─ WiFi（预留）                 ←→ 后续远程控制
 ├─ LEDC PWM → TEC 功率级（24V，15kHz）
 ├─ LEDC PWM → 风扇 PWM 脚（25kHz，经 3.3V→5V 接口）   ← TACH 测速反馈
 ├─ OneWire ← DS18B20（柜内/冷侧/热侧）
 ├─ ADC     ← NTC（主控板温，可选）
 ├─ I2C     ← INA226（供电监测）
 └─ 软关机锁存（GPIO13）；预留 GPIO32/33/34（原旋钮）
```

**电源树（v2.1）**

| 级 | 输入 | 输出 | 器件（参考） | 说明 |
|---|---|---|---|---|
| 输入保护 | USB-C VBUS / DC Jack | VBUS_SYS | TVS(SMBJ30A) + PTC(5A) + 防反接(P-MOS/肖特基) | 反接/浪涌，耐压 ≥40V |
| PD Sink | USB-C CC1/CC2 | 20V/65W 请求 | **CH224A** | 自带上拉；单电阻/I/O 配置 20V@3.25A |
| 逻辑 Buck | VBUS_SYS 5~24V | 3.3V@0.3A | MP2315 / TPS62125 / SY8303 | **宽压**：PC 5V 烧录自举 + PD 20V 均可用 |
| 功率 Boost | 20V | 24V@3.5A | LM3478 + 外置 N-MOS + 栅驱(U9) | 供 TEC 24V 母线；持续 2.5A(60W) |
| 5V Buck | 24V | 5V@1A | TPS54202 / MP2315 | 供栅极驱动(U9 VDD) + 风扇 PWM 接口(AHCT125 VCC/5V 上拉) |
| TEC 驱动 | 24V | 24V PWM | 低侧 N-MOS + 续流 | 见 §3.3 |
| 风扇开关 | 5V | 5V 通断 | 低侧 N-MOS（可选） | 见 §3.4 |

> **注意**
> - PD3.0 PDO 最高 20V，24V 必须由 Boost 升压获得。TEC 额定 **24V/3A（约 72W）**，持续按 60W（≈2.5A）运行 → 占空比上限约 83%，且瞬时电流必须 ≤ Imax（见 §3.3）。
> - **12V 轨已取消（v2.1）**：若机箱风扇为 12V 额定，其电机供电需另想办法（如选 **5V 兼容/低压启动风扇**，或对 5V 母线再升/降）。风扇**控制/反馈**逻辑仅需 5V + 3.3V。

## 3. 外围功能电路

### 3.1 PD Sink（CH224A，自带上拉）

- **定稿 = CH224A（WCH）**：USB PD 受电芯片（PD3.2/EPR 最高 140W 档可用），内置配置上拉，支持**单电阻配置 / I/O 电平配置**（部分封装支持 I2C）。
- **功能**：通过 USB-C CC 通道向适配器请求 **20V@3.25A（65W）**。
- **原理图连接**
  ```
  J1.CC1/CC2 ──► CH224A.CC1 / CC2     （芯片内置 sink 角色，勿再并 5.1k）
  J1.VBUS(经输入保护) ──► CH224A.VBUS  （自带高压 LDO 自供电，VDD 端 ≥1µF 去耦）
  CH224A.CFG ──► 单电阻/IO 配置 = 请求 20V 档（阻值按 CH224A 手册表）
  CH224A.PG ──► (可选) 供 MCU 读取取电就绪
  GND ──► 地
  ```
- **设计要点**
  - CC 只接 CH224A；VBUS 端 ≥35V 储能电容（100µF 电解 + 22µF 陶瓷）。
  - 配置目标电压（20V）必须与所需功率一致：按 CH224A 手册单电阻表取值并复核。
  - 供电信息（PD/电压档）由固件经 FFB5 `supply_protocol/max_power` 上报并限功率（协议 v1.2）。

### 3.2 电源树实现要点

- **逻辑 3.3V 宽压 Buck**：5~24V 输入。PC(5V) 与 PD(20V) 都可用；PD 协商 5V→20V 跳变时保持输出。
- **20V→24V Boost**：TEC 持续 2.5A（60W），Boost 需按 **≥3A/24V（~75W 峰值）** 设计并留裕量；输出 24V 母线加 **大电解 + 陶瓷** 支撑 PWM 斩波瞬态；输入侧注意 20V PTC 载流。
- **24V→5V Buck（v2.1，取代 24→12）**：5V 母线 ≤1A，从 24V 取电。用途：
  - **U9 栅极驱动 VDD（5~25V 工作，5V 足够）**；
  - **风扇 PWM 接口**（74AHCT1G125 VCC=5V）；
  - 预留 5V 逻辑（如需 USB 5V 器件）。
  - ⚠️ **无 12V 轨**：若风扇电机为 12V 额定，需自配电机供电（低压启动/5V 风扇，或另加 12V 小路），控制/反馈逻辑不受影响。
- 3.3V 加 LC 滤波（ESP32 射频敏感）。

### 3.3 TEC 24V 功率驱动（核心）

- **拓扑**：低侧 N-MOS 斩波，15kHz；续流 **Schottky** 跨 TEC；24V 母线大电容。
- **选型约束（重要）**：TEC 额定 24V/**3A（Imax）**。
  - 持续 60W → 占空比上限 ≈ 60/(24×3) ≈ **83%**；
  - 开通瞬时电流 = 24V/R，须保证 **≤ Imax**，避免超过 TEC 额定；
  - 栅极：低侧 N-MOS（TEC 支路）由 **U9 UCC27517 栅极驱动**驱动，U9 **VDD=5V（5V 母线）**，输入 IN± 接 ESP32 3.3V PWM（15kHz）；大栅荷/快速开关由栅驱保证。
  - 固件侧 `PELTIER_FULL_POWER_W` 应按 **24V 母线 + 该 TEC 的 R** 换算占空比-功率，供电识别 clamp（协议 v1.2）据此限幅。
- **保护**：INA226 实时监测母线电压/电流/功率；过流/过功率→降载或停机（报警码 5）。

### 3.4 风扇接口电路（4针）

- **电源**：电机电压按 §1/§3.2 注意项（v2.1 无 12V 轨；5V 兼容风扇接 5V 母线，或另供电机电压）。低侧 N-MOS **电源总闸**可选。
- **调速**：走风扇 **PWM 脚**（4 号，25kHz）。**PWM 接口（回答 3.3V 是否可直驱）**：
  - 直连 3.3V PWM 对多数 4 针风扇可用（阈值通常 ~2.5V），但 ATX 规范要求 5V 开漏驱动，个别风扇全速档不满；
  - **推荐用 74AHCT1G125 缓冲（非反向，VCC=5V 来自 5V 母线）**，连接如下：
    ```
    ┌─ 74AHCT1G125 (SC70-5/SOT23-5)
    OE(①)─► GND（低有效 = 常使能；勿接 3.3V IO，否则输出被禁用高阻）
    GND(②)─► GND
    A (③)◄── ESP32 GPIO26（3.3V PWM 输入，AHCT 阈值 ~2V 兼容）
    Y (④)─► 100Ω~1k 串阻 ──► 风扇 PWM 脚（Y 推挽输出 0/5V）
    VCC(⑤)─► 5V 母线（决定 Y 高电平；非"拉高"，是供电）
    ```
    - Y 为**推挽输出**，VCC=5V 时高电平主动到 5V，与风扇内部 5V 上拉一致 → **该线无需外部上拉**；
    - OE 必须接 GND 常使能；A/Y 同相，无占空比反转；
    - 复位/烧录期间 ESP32 高阻也不会被风扇内部上拉倒灌。
  - 备选 **2N7002 开漏 + 5V 上拉**：注意开漏会**反相**（PWM 高→拉低→降速），固件需反相或改用缓冲器。
- **测速**：TACH 开漏 → 10k 上拉 3.3V → GPIO27（2 脉冲/转）。闭环调速与堵转报警（报警码 6）依赖它。

### 3.5 电气量监测（INA226）

同前：5mΩ Kelvin 采样输入母线，I2C 0x40；量程按 TEC 峰值电流留裕（5A）。为供电识别（PD/QC/12V）与过流/过功率提供数据。

### 3.6 温度采集

DS18B20×3（柜内防水 / 冷侧 / 热侧 TO-92），单总线 4.7k；顺序与固件一致。NTC 板温（GPIO36）可选。

### 3.7 LED 状态指示（可选，替代 OLED）

- 1× 运行/连接指示（GPIO 自由选，如 32）
- 1× 报警指示（如 33）
- 或 LED 并入现有 GPIO；固件 `LED` 任务按需。

### 3.8 USB-UART 下载桥（CH340K，独立供电 + 防灌）

- **选型（定稿 = CH340K）**：内置晶振、小封装，成本低。
- **独立供电（v2.1，关键）**：CH340K **不挂在 ESP32 的 3.3V 逻辑轨上**，改由 **USB VBUS 电源路径**独立供电：
  - 插电脑下载：VBUS(5V) 直接给 CH340K VCC（经负载开关或低跌落路径），与主控 3.3V 解耦；
  - 正常 PD 供电：CH340K 可由 5V 母线或 VBUS 保持待机（不枚举，不影响取电）；
  - 目标：**任一域掉电都不能拖垮另一域**（CH340K 域由 VBUS 供电，MCU 域由 3.3V 供电）。
- **防灌（v2.1，关键）**：ESP32 与 CH340K 之间的信号在**不同电源域**，UART/控制线必须防灌：
  - `CH340K.TXD → ESP32.RX0`：串 **1kΩ 限流电阻**（必要时加钳位二极管到 3.3V）；
  - `CH340K.RXD ← ESP32.TX0`：同样串 1kΩ；
  - RTS#/DTR# 自动下载反相级（2×NPN/2N7002）本身即隔离，GPIO0/EN 侧上拉到 3.3V，IO 侧以集电极开路驱动；
  - 任一侧断电时，串联电阻/开漏结构保证**不会经引脚向对方反向供电**。
- **自动下载**：RTS#/DTR# 经 2×NPN/2N7002 反相接 GPIO0/EN；**RTS#/DTR# 引出情况以 CH340K 数据手册为准**，若无则改手动 BOOT/EN。
- **烧录自举**：逻辑 3.3V 由宽压 Buck（5~24V）从 VBUS_SYS 得到；PC 插入（5V）即可点亮 ESP32 下载。

### 3.9 Type-C 焊接友好替代（J1）

- 卧贴 16P 引脚细；手焊建议用 **Type-C 转 2.54 排针模块**或**面板母座 + 延长线**接到主板端子（主板只留大间距焊盘），量产再考虑 16P 混装（4 插件脚 + SMD 信号脚）。

### 3.10 保护与 EMC

- 输入 TVS(SMBJ30A)+PTC(5A)+防反接。
- 24V Boost + PWM 斩波：母线大电容、续流、栅极串阻抑制振铃；功率走线加宽。
- INA226 Kelvin 采样；地单点。
- ESP32 天线净空；金属结构远离 ≥10mm。
